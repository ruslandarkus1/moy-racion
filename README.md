# Мой рацион

Бесплатный автономный планировщик питания: **253 рецепта**, меню на неделю, список покупок, замена блюд и выбор магазина.

## Скачать приложение на Android

### [⬇ Скачать legkost.apk](https://github.com/ruslandarkus1/moy-racion/raw/refs/heads/main/legkost.apk)

1. Открой эту страницу на телефоне или планшете Android.
2. Нажми «Скачать legkost.apk» выше.
3. Открой скачанный файл в папке «Загрузки» и нажми «Установить».
4. Если Android запросит разрешение на установку из этого браузера или файлового менеджера, разреши его для установки. Затем разрешение можно отключить.

Требуется **Android 8 или новее**, актуальный Android System WebView. Приложение работает без интернета, оплаты, регистрации и Termux. APK подписан; подпись и ресурсы проверены. На физическом Android пока не тестировалось.

## Файлы проекта

- [legkost.apk](./legkost.apk) — приложение Android.
- [legkost-github.zip](./legkost-github.zip) — исходники сайта, Android-оболочки и инструкции. Для просмотра исходников скачай и распакуй архив.

В архиве: `source/public` — сайт и рецепты; `android/src` — код Android; `tools/build_pages.py` — сборка сайта; `NOTICE.txt` — происхождение ресурсов.

Персональные ответы, настройки и меню хранятся только на конкретном устройстве. Они не загружаются в этот репозиторий и не синхронизируются автоматически. Для переноса используй резервную копию в настройках.

Это самостоятельная бесплатная версия планировщика. Закрытый сервер и платные рецепты исходного сервиса не копировались. Публичные ресурсы исходного опроса сохраняют права их авторов; сведения приведены в NOTICE.txt внутри архива.
